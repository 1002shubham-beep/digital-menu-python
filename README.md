# 🍔 Digital Menu

> My first Python project — a simple interactive restaurant ordering system built while learning Python.

## 📌 About the Project

**Byte & Bite** is a beginner-friendly digital restaurant menu made using Python.

The program interacts with the customer through the terminal and guides them through a simple ordering process.

## ✨ Features

* 👋 Welcome message for customers
* 🍔 Multiple food categories
* 🥪 Different food types and prices
* 🔢 Quantity selection
* ✅ Order confirmation
* ❌ Order cancellation
* 💬 Interactive terminal-based experience

## 🍽️ Menu

| Item            | Starting Price |

## ▶️ How to Run

Make sure Python is installed on your computer.

Clone the repository:

```bash
git clone https://github.com/YOUR-USERNAME/digital-menu-python.git
```

Navigate into the project:

```bash
cd digital-menu-python
```

Run the program:

```bash
python digital_menu.py
```
